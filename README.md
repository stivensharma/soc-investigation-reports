# SOC Investigation Reports

Portfolio of incident investigation write-ups demonstrating alert triage, timeline construction, MITRE ATT&CK mapping, IOC documentation, and response recommendations.

All scenarios and data are fictional and created for demonstration purposes.

## Reports

| ID | Title | Focus |
|----|-------|-------|
| IR-2026-001 | Phishing Link Leading to Credential Use and Anomalous Sign-In | Phishing, credential access, MFA |
| IR-2026-002 | Macro-Enabled Document Leading to Obfuscated PowerShell Execution | Endpoint, macro, PowerShell, C2 |
| IR-2026-003 | Brute-Force Success Against Contractor VPN Account | VPN, brute force, initial access |
| IR-2026-004 | Suspicious Sign-In and PowerShell Execution Correlated in Microsoft Sentinel | Microsoft Sentinel, KQL, correlated detections |

Each report includes an executive summary, timeline, technical analysis, ATT&CK mapping, indicators, scope, actions taken, and recommendations.

## Tools & Concepts Demonstrated

- Microsoft Sentinel / KQL
- Endpoint telemetry (process trees, network connections)
- Azure AD / Entra ID sign-in analysis
- MITRE ATT&CK technique mapping
- Phishing and credential harvesting triage
- Containment and response actions
